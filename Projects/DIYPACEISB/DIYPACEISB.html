Introduction


I would like to add the Instant Set-Back (ISB) feature to my soldering iron, but unfortunately PACE do not sell an upgrade kit for users with an existing tool stand - you have to buy an entirely new tool stand (very expensive)! I came across this article that shows how to DIY this using a simple LED and light sensor circuit:


PACE Instant Setback Cubby

Taking this information I was able to put something together that works in the same way but using parts I had lying around at home. The main parts are listed below:


IR Sensor


PIC16F88 Microcontroller


3-Pin Mini-DIN Connector



Schematic


The schematic is hand-drawn because the circuit is implemented on a solderable breadboard (I didn't want to create a custom PCB for such a simple project).

Firmware


I challenged myself to write the entire code in assembly, to brush up on my PIC assembly language skills. Since this is such a simple project, it was relatively straightforward to program the IC. After configuring the microcontroller clock to run at 8 MHz using the internal RC oscillator, I wrote a simple bit-bang UART that I used to transmit the value read back from the IR sensor, which is useful for determining the threshold value for when the iron is or is not in the tool stand. Once the threshold value was found, the microcontroller switches the state of pin RB7, either to an output low, or to an input (simulating an open drain output, or a physical switch connected to the ISB cubby which connects the sense pin to ground). This triggers the PACE station and tells it when to lower the soldering iron temperature.
